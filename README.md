# NYU Music Technology Capstone
## Description:
This repository contains the research, learning, and final product (to come) for my New York University Music Technology Senior Capstone Project

The prose of this project is to learn audio applications for machine learning starting from very experience

The proposed final product in an embedded system that intelligently updates parametric EQ settings for guitar. My goal is not to create the perfect product (though it would be nice), but to learn machine learning and see what the hype is! I will be comparing my perception of this project to traditional signal processing techniques such as static EQ and multi-band compressors
